# LED Config Reader

A free, browser-based reader for **NovaStar `.rcfgx`** LED receiving-card config files.
Drop a file and get a full spec card, plain-words checks, and a **Light-up Preview** of how the
module scans and how a picture looks with that file's gamma, brightness and gray depth.

**Everything runs in your browser.** Nothing is uploaded, nothing is sent to a screen.

Live: https://katviz.github.io/vr-led-control-room/

By [Visual Rhyme](https://visualrhyme.digital) · the LED display brand of Microtronix Solution.
